DESARROLLO WEB

HTML , CSS y JavaScript:

Son los tres pilares fundamentales del desarrollo web que trabajan juntos para crear paginas web dinamicas e interactivas. HTML se encarga de la estructura y el contenido, CSS del diseño y la presentacion, y JavaScript de la interactividad y la funcionalidad.

Definiciones:

HTML (HyperText Markup Language)

Es el lenguaje de marcado que define la estructura y el contenido de una pagina web.Utiliza etiquetas para delimitar diferentes elementos, como parrafos, encabezados, imagenes, enlaces, etc.

CSS (Cascading Style Sheets)

Es un lenguaje de estilos que se utiliza para controlar la presentacion de una pagina web.Permite definir aspectos como los colores fuentes tamaños, margenes, etc., de los elementos HTML.

JavaScript (Lenguaje de Programacion)

Es un lenguaje de programacion que permite agregar funcinalidad interactiva a una pagina web. Permite manipular elementos HTML., responder a eventos del usuario, realizar calculos, etc.

Analogia de la web y una casa:

HTML

Estructura de la casa.Es como los cimientos, las paredes, techos y distribucion de las habitaciones. HTML define la estructura basica de una pagina web que elementos hay(titulos, parrafos, botones, imagenes, etc.), pero sin preocuparte por como se ven.

CSS

Decoracion y estilo de la casa. Es la pintura de las paredes,el tipo de piso, los muebles, las cortinas, el diseño de la cocina. CSS se encarga de como se ve la pagina: colores, fuentes, margenes, alineaciones, estilos responsivos... los visual.

JavaScript

Los sistemas electricos y electronicos de la casa. Es como los interruptores que encienden luces, las puertas automaticas, el termostato inteligente. JavaScript añade funcionalidad e interactividad haciendo que pasen cosas como respuesta a un evento.

Resumen

"Los tres lenguajes son esenciales para el desarrollo web y cada una juega un paper crucial en la creacion de paginas web modernas y funcionales"
